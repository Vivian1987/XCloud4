# Cómo jugar si tu país no tiene Xbox Cloud Gaming

Algunos usuarios informan de que funciona este método. No está garantizado y puede dejar de funcionar en cualquier momento:

1. Conectado a una VPN de un país donde Xbox Cloud Gaming está disponible, crea una cuenta de Microsoft nueva con ese país como región.
2. Con esa cuenta, entra una vez en xbox.com para crear el perfil de Xbox (gamertag). Para jugar al catálogo necesitas Game Pass Ultimate en esa cuenta; para Fortnite basta la cuenta gratuita.
3. En la PS4 (sin VPN), inicia sesión en XCloud4 con esa cuenta.
4. En OPTIONS > Servidor, elige el servidor más cercano a ti. Tras jugar una partida en cada uno verás sus ms reales; elige el de menos ms.

Riesgos: crear una cuenta con un país que no es el tuyo puede ir contra los términos de Microsoft y Xbox. Tu cuenta podría ser suspendida y puede haber problemas con pagos y suscripciones de otra región. Lo haces bajo tu propia responsabilidad; XCloud4 no se hace responsable.

Lista oficial de países con Xbox Cloud Gaming: https://www.xbox.com/regions

XCloud4 no modifica ni falsea tu ubicación: solo usa lo que Xbox permite a tu cuenta.
